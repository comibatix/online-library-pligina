# Фронтенд Онлайн-библиотеки

Клиентская часть веб-приложения для поиска книг, управления списком чтения и лайками.

---

## Технологический стек

- **Фреймворк:** React 18
- **Сборщик:** Vite
- **Язык:** TypeScript
- **Маршрутизация:** React Router v6
- **Стилизация:** Tailwind CSS
- **HTTP-клиент:** Axios
- **Управление состоянием:** React Hooks (`useState`, `useEffect`, `useContext`)
- **Хранение данных:** `localStorage` (для JWT-токена)

---

## Быстрый старт

### Предварительные требования
- Убедитесь, что бэкенд запущен и работает на `http://localhost:5000`

### Установка и запуск
```bash

# 2. Установите зависимости
npm install

# 3. Запустите сервер разработки
npm run dev

Приложение будет доступно по адресу: http://localhost:3000

Ключевые особенности реализации

Маршрутизация и защита страниц
Используется React Router для навигации без перезагрузки страницы (SPA).
Приватные маршруты (/my-likes, /reading-list, /profile и др.) защищены: при отсутствии валидного JWT-токена в localStorage происходит редирект на страницу /login.

Работа с API
Все запросы к бэкенду выполняются через Axios.
JWT-токен автоматически добавляется в заголовок Authorization: Bearer <token> для защищённых эндпоинтов.
Реализована обработка состояний загрузки (loading spinner) и ошибок (вывод сообщений пользователю) на всех страницах.

UI/UX
Адаптивная вёрстка: интерфейс корректно отображается на мобильных устройствах и десктопах (благодаря Tailwind CSS).
Пагинация: реализована на всех списках (поиск книг, лайки, список чтения, комментарии) для удобного просмотра большого объёма данных.
Живой поиск: на странице "Мои книги" реализован поиск с задержкой (debounce) для оптимизации запросов.
Обложки книг: отображаются везде, где есть информация о книге. Если обложка отсутствует, показывается плейсхолдер.

Переменные окружения
Файл .env (создаётся на основе .env.example):
# URL бэкенда API
VITE_API_URL=http://localhost:5000

# Порт для Vite (опционально)
VITE_PORT=3000

Сборка для продакшена
npm run build

Оптимизированные файлы будут сгенерированы в папке dist/.
